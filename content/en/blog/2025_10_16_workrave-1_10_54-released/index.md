Workrave 1.10.54 has been released. This release adds support for GNOME Shell 49.

<!--more-->

Changes since Workrave 1.10.53:

- Add support for GNOME Shell 49 ([#636](https://github.com/rcaelers/workrave/issues/636), Alessandro Astone)

Changes since Workrave 1.10.52:

- Fix GNOME Shell 46 support ([#532](https://github.com/rcaelers/workrave/issues/532))
- Add support for GNOME Shell 47 and 48 ([#601](https://github.com/rcaelers/workrave/issues/601))

Changes since Workrave 1.10.51:

- Fix GNOME 45 compatibility ([#508](https://github.com/rcaelers/workrave/issues/508))

Changes since Workrave 1.10.50:

- Support GNOME Shell 43 ([#430](https://github.com/rcaelers/workrave/issues/430) by Jeremy Bich)
- Add option to force the use of the X11 Gtk backend on Wayland
- Support GNOME Shell 44 ([#487](https://github.com/rcaelers/workrave/issues/487))
- Fix crash on Linux when not using GNOME.
