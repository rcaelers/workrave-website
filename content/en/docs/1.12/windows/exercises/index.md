---

Workrave shows a number of exercises at the start of a restbreak.
The exercises can also be started manually from the [menu](/docs/1.12/menus).

The player is shown below in **Classic** and **Sanctuary** appearances. Select **Use Sanctuary UI** in [Preferences → User interface → General](/docs/1.12/settings/ui/#general) to choose the appearance. Select an image to view it at full size.

{{< ui-comparison alt="Exercises" classic="/images/screenshots/1.12/exercises.png" sanctuary="/images/screenshots/1.12/exercises-sanctuary.png" >}}

The buttons can be used to go to the previous exercise, to pause the exercises, to go to the next exercise and to stop showing exercises.
