---
title: Software updates
lastmod: 2026-10-12
---

Builds that include the update checker can check for new Workrave releases. Open
**Preferences → Plugins → Software updates** to configure the checks.

- **Automatically check for updates** enables regular update checks.
- **Get updates as soon as they are available** controls how promptly new
  releases are offered.
- **Release channel** selects which releases to check for. The normal release
  channel is **Stable**.
- **Proxy Type** and **Proxy** configure how the update checker connects.
  **System proxy** uses the operating system's proxy settings.

You can also select **Check for Updates** from the Workrave menu to check
manually. These settings affect the update checker, rather than break timers.

If your package does not include the update checker, use your operating system's installer or package manager, or check the [downloads page](/download/).
