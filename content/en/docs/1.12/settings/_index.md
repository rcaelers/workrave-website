Workrave's Qt preferences use a sidebar with sections and pages. Open **Preferences** from the timer-window or tray menu.

- [Timers](timers)

  Contains all settings for the three breaks.

- [User Interface](ui)

  Settings for several aspects of the user interface.

- [Monitoring](monitoring)

  **Timers → Monitoring** contains activity-monitoring settings and, on supported Windows builds, Focus Assist integration.

- [Sounds](sounds)

  **User interface → Sounds** contains settings for the sounds Workrave plays.

- [Remote control](remote-control)

  **Remote control → gRPC** is available in builds with gRPC support.

- [Software updates](updates)

  Settings for the optional update checker under **Plugins → Software updates**.

Select **Timers → Micro-break**, **Rest break** or **Daily limit** to configure a break:
