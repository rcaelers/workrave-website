Workrave's settings are divided into the following sections.

- [Timers](timers)

  Contains all settings for the three breaks.

- [User Interface](ui)

  Settings for several aspects of the user interface.

- [Monitoring](monitoring)

  Settings for activity monitoring and Windows Focus Assist.

- [Sounds](sounds)

  Settings for the sounds Workrave plays.

- [Software updates](updates)

  Settings for checking for new releases on Windows.
