title: Applets
---
On several Linux desktop environments, Workrave can show the timers
in the status bar or panel. This way the timers are always visible
without using precious space on your screen.

Currently, this is supported on the following platforms:

- [Cinnamon](cinnamon)

- [Gnome](gnome)

- [KDE](kde)

- [MATE](mate)

- [Xfce](xfce)

The Windows DeskBand applet was removed in 1.11. Windows users can use the [timer window](/docs/1.11/windows/main/) and [tray icon](/docs/1.11/menus/tray-icon/).
